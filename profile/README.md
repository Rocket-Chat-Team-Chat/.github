# Rocket.Chat - Team Chat with Channel List and Thread View

## About Rocket.Chat

Rocket.Chat is team chat you operate or were given. Rocket.Chat Team Chat is the product. Rocket.Chat Channel List is the room list. Rocket.Chat Thread View is a decision that stays readable. Rocket.Chat Self Host is your own server when policy wants that. Rocket.Chat Live Chat is a support queue on a host you run, not a scrape of strangers.

Open only Rocket.Chat Team Chat on a host you trust. Keep Rocket.Chat Channel List as rooms you still use. Use Rocket.Chat Thread View for a decision, not as a dump. Use Rocket.Chat Self Host when the architecture says the store stays on your machines. Use Rocket.Chat Live Chat only for visitors who opened a page you operate.

Rocket.Chat Team Chat, Rocket.Chat Channel List, Rocket.Chat Thread View, Rocket.Chat Self Host, and Rocket.Chat Live Chat exist to talk in rooms you already operate.

## Key Features of Rocket.Chat

- **Team chat as the workspace** – Rocket.Chat Team Chat is membership and the inbox of rooms. Rocket.Chat Channel List lives here. Rocket.Chat Thread View opens from a message. Rocket.Chat Self Host is optional unless policy requires it. Rocket.Chat Live Chat is a named extra for a desk you run.
- **Channel list as the rooms** – Rocket.Chat Channel List is named rooms. Mute noise. Rocket.Chat Team Chat then stays readable. Rocket.Chat Thread View still belongs to one room. Rocket.Chat Self Host does not change the need to leave unused rooms. Rocket.Chat Live Chat should land in a named room, not all of them.
- **Thread view as a decision** – Rocket.Chat Thread View keeps a decision off the main timeline. Search a unique token. Rocket.Chat Team Chat still owns retention. Rocket.Chat Channel List is how you got there. Rocket.Chat Self Host still stores it. Rocket.Chat Live Chat should not flood a thread you meant to read.
- **Self host as your server** – Rocket.Chat Self Host is when you run the chat server. Use it when policy wants traffic on your machines. Rocket.Chat Team Chat still needs a name. Rocket.Chat Channel List still needs owners. Rocket.Chat Thread View still needs discipline. Rocket.Chat Live Chat then points at you.
- **Live chat as a queue you run** – Rocket.Chat Live Chat is visitors on a page you operate. Staff it. Rocket.Chat Team Chat should still show a person as a person. Rocket.Chat Channel List should still have a destination room. Rocket.Chat Thread View should still be human when a decision matters. Rocket.Chat Self Host should still log who staffed the queue.

## Quick Start with Rocket.Chat

1. **One team** – Open Rocket.Chat Team Chat you were given. Pin two rooms in Rocket.Chat Channel List. Ignore Rocket.Chat Thread View until a send works. Ignore Rocket.Chat Live Chat. Ignore Rocket.Chat Self Host if you were given a host you may use.
2. **Use a thread** – Start Rocket.Chat Thread View on a decision. Search a token later. Rocket.Chat Channel List unchanged. Rocket.Chat Team Chat unchanged. No Rocket.Chat Live Chat yet. Rocket.Chat Self Host unchanged.
3. **Self host only if policy** – Point Rocket.Chat Self Host at a server you operate. Create Rocket.Chat Team Chat there. Build Rocket.Chat Channel List. Test Rocket.Chat Thread View. Enable Rocket.Chat Live Chat only on a page you operate.
4. **Trim** – Leave rooms in Rocket.Chat Channel List you do not operate. Archive old Rocket.Chat Thread View if policy says so. Recheck Rocket.Chat Team Chat membership. Recheck Rocket.Chat Live Chat hours. Recheck Rocket.Chat Self Host backup.
5. **Review** – Rocket.Chat Team Chat names still match the job. Rocket.Chat Channel List short. Rocket.Chat Thread View not a dump. Rocket.Chat Live Chat still a queue you staff. Rocket.Chat Self Host still in scope.
